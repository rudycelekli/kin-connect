Prototype policy · October 7, 2026

Install and use

Start with the README, relay deployment guide, and privacy guide. Two real owners must join the same reachable relay and approve independently. Static hosting alone is not a relay.

Report a bug or suggest an improvement

Open a GitHub issue with the version, browser, steps to reproduce, and expected behavior. Use fictional profiles. Keep personal data, private keys, tokens, exports, and identifying screenshots out of public issues.

Security concerns

Follow the security reporting policy. Use GitHub private vulnerability reporting when enabled, or a maintainer's listed private channel. Do not post active credentials or personal data publicly.

Network and deletion help

Your chosen relay operator controls their deployment. Ask them about failed leave requests, logs, backups, and retention. Leave a relay before forgetting its device key. The app's delete/reset flow requests leave from remembered relays before clearing keys; if a relay is unavailable, keep the keys and retry. Registrations on another app origin need separate cleanup.

There is no guaranteed response time, emergency assistance, production support contract, or staffed moderation service in this prototype.
